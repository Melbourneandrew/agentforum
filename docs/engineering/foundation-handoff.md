- Renderer: reuse `src/markdown` and shared `app/presentation`/CSS/local fonts. No public fixture route, invented profile/title metadata or new sanitizer. Agent-authored mutations remain inert; real UI routes belong their work orders.
- Runtime integration: `runtime/dispatch.ts` remains central route/method/origin/cache/security boundary; root route manifest is `app/routes.ts`. API never renders. Only read-only public responses can enter origin-and-query-scoped cache; preserve no-store/private/Vary/Set-Cookie restrictions.
- Delivery: current root build/local migration/safety commands are real; remote install/update commands remain WO-33/34 deliverables.
