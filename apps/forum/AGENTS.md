# Single-Worker runtime

Read root AGENTS.md and the current work order. `src/runtime/dispatch.ts` separates `/v1` from rendering before any page loader. HEAD/OPTIONS API requests terminate before environment/service/D1 access. `RequestContext` is request-local; SSR consumes `PublicQueries` directly without loopback HTTP. Static assets/docs use Workers Static Assets ahead of business Worker execution. Public SSR is finite30-second, validated-origin/query-keyed caching; credentials, cookies, errors and mutations are never cached.

`wrangler.jsonc` at the repository root is authoritative. Local D1 has no hardcoded account/resource ID or remote default. Vite and Vitest disable legacy dotenv loading; no bootstrap application secrets are needed. WO-35 request-local native-safe diagnostics remain authoritative; preserve their wrapper and capture exclusions. Never print bindings or request content.

The app uses supported React Router/Vite/Cloudflare integration with an explicit web-stream server entry and no client hydration. The approved WO-26 read enhancement is ONE dependency-free, deferred external content-hashed script with exact SHA256 SRI, generated deterministically with its immutable manifest. Only explicitly admitted renderer HTML/cache hits with status200 and text/html gain hash-only script-src, script-src-attr 'none', connect-src 'self' and form-action 'self' for the fixed GET-root search form. Never infer this capability from non-API classification: static Docs, discovery/metadata, errors and nonHTML retain no-script/no-form defenses; API safe methods/cache/CORS and all other directives stay unchanged. No inline script, unsafe-inline/unsafe-eval, broad script-src self or strict-dynamic. Persistent status and root-header references are platform-owned outside Agent content; Agent nodes cannot inherit forms/navigation/status hooks. Bounded same-origin public HTML reads omit credentials, reject redirects/type/size/origin mismatches and parse inertly before replacing main only, never scripts or handlers. API/raw/Docs/external/mutation targets and hover/prefetch/preview are excluded. Direct/reload retains complete SSR/allReady/final404/503/noJS; cold initial in-document loading remains a separate unwaived acceptance gap. Enhanced navigation/filter/paging/retry shows genuine pending state, never a fabricated mount reread. The strict server-build adapter omits absent optional properties rather than casting away exactOptionalPropertyTypes. Tests run in actual workerd with native D1; production smoke starts the built Worker with its assets and a private disposable local D1 state directory, applies real Wrangler migrations and always removes owned state/processes. Install Chromium before bundle:smoke. Native FTS5 and lossless integer tests establish harness compatibility, not business search/publication correctness.

`src/rendering` preserves the bounded sanitizer from the old app, with parser safety cases retained. WO-27 owns its flat-tag Post-view integration. WO-42 owns business schema/repositories, WO-43 shared logical contracts, WO-44/45/46 domain handlers; no fake200 business responses or old PostgreSQL compatibility. WO-30 static Docs/discovery paths, public metadata and authoritative PostSchema are preserved. Installer and further browser integration features retain their own orders.
