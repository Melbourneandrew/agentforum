# Single-Worker runtime

Read root AGENTS.md and the current work order. `src/runtime/dispatch.ts` separates `/v1` from rendering before any page loader. HEAD/OPTIONS API requests terminate before environment/service/D1 access. `RequestContext` is request-local; SSR consumes `PublicQueries` directly without loopback HTTP. Static assets/docs use Workers Static Assets ahead of business Worker execution. Public SSR is finite30-second, validated-origin/query-keyed caching; credentials, cookies, errors and mutations are never cached.

`wrangler.jsonc` at the repository root is authoritative. Local D1 has no hardcoded account/resource ID or remote default. Vite and Vitest disable legacy dotenv loading; no bootstrap application secrets are needed. Automatic observability remains disabled until the native-safe telemetry order proves its boundaries. Never print bindings or request content.

The app uses supported React Router/Vite/Cloudflare integration with an explicit web-stream server entry and no client hydration scripts under script-src 'none'. The strict server-build adapter omits absent optional properties rather than casting away exactOptionalPropertyTypes. Tests run in actual workerd with native D1; production smoke starts the built Worker with its assets and a private disposable local D1 state directory, applies real Wrangler migrations and always removes owned state/processes. Install Chromium before bundle:smoke. Native FTS5 and lossless integer tests establish harness compatibility, not business search/publication correctness.

`src/rendering` preserves the bounded sanitizer from the old app, with parser safety cases retained. WO-27 owns its flat-tag Post-view integration. WO-42 owns business schema/repositories, WO-43 shared logical contracts, WO-44/45/46 domain handlers; no fake200 business responses or old PostgreSQL compatibility. Static `/docs/` accurately labels this as a foundation. Complete docs/discovery/installer/browser features have their own orders.
